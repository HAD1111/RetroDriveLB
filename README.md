# Retro Drive LB

A tribute to living machines, Lebanese road culture, and classic-car restoration founded around Charbel Maroun Mehawej’s lifelong passion for vintage automobiles.

## Features
- **Editorial Automotive Aesthetic:** Nostalgic 1960s–1980s magazine-inspired layout with organic section transitions, typography, and genuine workshop archives.
- **Interactive V8 Audio Engine:** Synthesized Web Audio API naturally aspirated V8 engine featuring mechanical starter motor cranking, continuous multi-harmonic idle (~700 RPM), and dynamic scroll-velocity throttle revving up to 3,000 RPM.
- **Before / After Restoration Slider:** Interactive split comparison of the 1970 Oldsmobile Cutlass nut-and-bolt rebuild.
- **Responsive Architecture:** Calibrated fluid layouts across 320px, 360px, 375px, 390px, 414px, 430px, 768px, 1024px, 1200px, and 1440px with zero horizontal overflow.
- **Atelier Services & Gatherings:** Overview of mechanical restoration, preservation services, and road convoys across Lebanon.
